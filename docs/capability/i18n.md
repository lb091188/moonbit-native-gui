# i18n (@i18n)

UI copy lookup: TOML catalogs, interpolation, plurals, locale-change subscriptions; built-in widget copy (dialogs, date pickers, edit menu, validation messages) is localizable the same way. `moon.pkg`:

```
"NoahLiu/native-gui/i18n" @i18n,
```

## Catalog format

A minimal TOML reader: top-level keys are the original strings; keys after a section header inherit the section prefix.

```toml
"Back" = "返回"
"Copy install command" = "复制安装命令"
[nav]
"Basics" = "基础组件"
[form]
min_len = "至少 {n} 个字符"
```

- Top-level keys must come before any section header (the reverse won't error — the whole table just resolves to nothing).
- `[meta] locale = "zh"` marks the language; put it last.
- Built-in widget catalog sections: `gui.ui.dialog` / `gui.ui.message_box` / `gui.ui.datepicker` / `gui.ui.validation` / `gui.ui.edit`.

## Loading & switching

```moonbit
@i18n.i18n_load(ZH_CATALOG)            // switch locale: load the catalog
@i18n.i18n_reset()                     // back to the built-in (Chinese) catalog
@i18n.i18n_load_fallback(ZH_CATALOG)   // fallback catalog (queried only when the current locale misses)
@i18n.i18n_extend(ZH_CATALOG)          // additive entries, existing keys untouched
@i18n.i18n_locale()                    // current locale code
```

Without loading a catalog, the built-in Chinese catalog (`builtin_default()`) is the base. Switching is a runtime action: `on_locale_change(f)` registers a callback and returns a handle, `off_locale_change(h)` unsubscribes; the refresh itself is driven by the app (showcase approach: broadcast + router `localize_remount` to remount page content in place).

## Lookup

| Function | Use |
|---|---|
| `t(key)` | Returns `None` when missing |
| `t_or(key, default)` | Falls back to `default` |
| `t_with(key, [("n", "3")])` | With interpolation; placeholders are `{name}` |
| `t_with_or(key, vars, default)` | Interpolation + fallback |
| `t_count(key, n)` | Plurals: picks the one/other form by language; use `{n}` for the count |
| `interp(tmpl, vars)` | Pure interpolation, no lookup |

Built-in widget copy needs no lookup: once a catalog is loaded, dialogs, date pickers, edit menus and validation messages follow it automatically.

## Key conventions

The showcase convention: the key is the original string (descriptions use `desc§` + the original title), group prefixes `nav.` / `seg.` / `form.` / `menu.`. That way the Chinese build runs with no catalog at all, and one catalog covers the whole English build.
