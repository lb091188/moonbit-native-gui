features:
  - title: 一套代码，三个平台
    details: Windows / Linux / macOS 原生窗口，控件观感一致；默认跟随系统深浅色与强调色，主题可定制。
  - title: 界面写成树，数据变了自动刷新
    details: 界面用代码声明成一棵树，mount_window 一步挂载；数据一变，绑定的界面自动刷新，不用手写刷新胶水。
  - title: 桌面能力开箱即用
    details: 托盘、通知、菜单、全局快捷键、文件对话框、拖放、剪贴板、开机自启，拿来就用。
  - title: 组件齐全
    details: 表单、表格、虚拟滚动、图表、Markdown 视图都有；内嵌浏览器与音视频播放按需另装，不拖累默认依赖。
  - title: 轻量
    details: 只编译你用到的部分，没用到的包不进程序；不依赖重型图形引擎，产物小、启动快。
  - title: 缺什么就明说
    details: 某项能力在这台机器上不可用时，会给出明确原因，不会悄悄失败，更不会崩溃。
