# 路线图

MoonBit 的**跨平台桌面 GUI 框架**——一套代码直出 Windows / Linux / macOS 原生窗口，系统能力开箱即用，`moon add` 后零配置运行。

本页只回答三件事：**做什么、做到哪了、还差什么**。

## 怎么读

全页按两栏分：**已实现**（含已规划且做了一半的）和**未实现但明确要做**。真正的非目标在文末「明确不做」。

**验证标准就是三平台**：测试状态打勾 = Windows / Linux / macOS 真机都过；只过了一两个平台、或还差子项的，写 🚧 并注明差在哪。

- **开发状态**：✅ 完成　🚧 进行中　⏳ 未开始
- **测试状态**：✅ 三平台都过　🚧 部分平台过（括号里注明差哪个）　⏳ 未验　— 不适用（文档类）
- **层级**：每个功能点一个一级条目，下面按分组列要点；组内再细分的用三级条目

## 平台与当前版本

- **Linux** · X11 主链路，兼容跨度 deepin 20 ~ Ubuntu 26，工具包留守 GTK3 · 真机已验（XFCE 主；KDE / GNOME / DDE 待排）
- **Windows** · 10 / 11，产物是 GUI 子系统 exe，双击不弹控制台 · 真机已验
- **macOS** · Apple Silicon（Intel 未验）· 真机已验

**当前版本 `0.2.0`**（2026-10-19）：主模块 + 四个扩展包同批首发，见文末「承诺与版本」。

## 明确不做

- **无障碍**：自绘文本栈暂不含，只记不办。
- **排印与绘制补口**：`letter_spacing`、`set_dashes`、代码高亮 / 终端 / WebGL 画布——不在计划内。
- **单平台能力进跨平台门面**：只有单一平台实现的能力不做门面，也不留挂账。
- **Linux 工具包升级**：留守 GTK3——它是 deepin 20 到 Ubuntu 26 的公共交集；不引入 Qt。脱 GTK 的唯一形态是降为可选后端。
- **原生控件皮肤**：不作主题化路径；按平台开关的原生兜底例外需逐条登记评审。
- **按参考实现平移接口**：接口由真实用例驱动，不为对齐而补。
- **macOS 四族**：窗口管理（Accessibility 授权门槛）、夜间色温（CoreBrightness 私有）、电源方案（`pmset` 语义对不上三值）、媒体播放器枚举（无 MPRIS 对等物）。
