# API 参考

完整 API 参考在 mooncakes.io，由源码 doc 注释自动生成：每个包的类型与函数签名、注释说明、源码行链接，页面可切换历史版本。

**[打开 native-gui API 参考 ↗](https://mooncakes.io/docs/NoahLiu/native-gui)**

各包直达：

| 包 | 内容 |
|---|---|
| [base](https://mooncakes.io/docs/NoahLiu/native-gui/base) | 响应式内核（`Store` / `Signal` / `ListStore`）、焦点栈、键码常量 |
| [shell](https://mooncakes.io/docs/NoahLiu/native-gui/shell) | 菜单、热键、托盘、通知、外部打开、定时器 |
| [widget](https://mooncakes.io/docs/NoahLiu/native-gui/widget) | 控件宿主：布局树、命中与事件路由、绘制遍历 |
| [ui](https://mooncakes.io/docs/NoahLiu/native-gui/ui) | 控件构造器全集（见[组件总览](../components/index.md)） |
| [render](https://mooncakes.io/docs/NoahLiu/native-gui/render) | 画布、位图、图像与 PNG（见[画布](../guide/canvas.md)） |
| [text](https://mooncakes.io/docs/NoahLiu/native-gui/text) | 字体族、字体、富文本与区间属性 |
| [theme](https://mooncakes.io/docs/NoahLiu/native-gui/theme) | 色板派生与变更订阅 |
| [icons](https://mooncakes.io/docs/NoahLiu/native-gui/icons) | 矢量图标 |
| [sys](https://mooncakes.io/docs/NoahLiu/native-gui/sys) | 系统能力（见[系统能力总览](../capability/sys.md)） |
| [input](https://mooncakes.io/docs/NoahLiu/native-gui/input) | 编辑内核与键码 |
| [win](https://mooncakes.io/docs/NoahLiu/native-gui/win) | 平台窗口层：窗口、快捷键、图标、输入法、消息框 |
| [dbus](https://mooncakes.io/docs/NoahLiu/native-gui/dbus) | Linux D-Bus 调用：托盘 SNI、通知、媒体、网络等 |
| [chart](https://mooncakes.io/docs/NoahLiu/native-gui/chart) | 图表与横切交互层 |
| [mdview](https://mooncakes.io/docs/NoahLiu/native-gui/mdview) | Markdown 渲染视图 |
| [style](https://mooncakes.io/docs/NoahLiu/native-gui/style) | 样式表（见[布局样式](../guide/layout.md)） |
| [i18n](https://mooncakes.io/docs/NoahLiu/native-gui/i18n) | 界面文案多语言 |
| [router](https://mooncakes.io/docs/NoahLiu/native-gui/router) | 单窗口页面路由 |

可选独立模块：[gui-media](https://mooncakes.io/docs/NoahLiu/gui-media)（音视频）、[gui-webview](https://mooncakes.io/docs/NoahLiu/gui-webview)（内嵌 WebView）。

用法与场景见左侧指南各页；本站只教使用，逐签名以 API 参考为准。
