# 多语言（@i18n）

界面文案查译：TOML 词表、插值、复数、语言切换订阅；内置控件文案（对话框、日期选择器、编辑菜单、校验提示）同样可本地化。`moon.pkg` 引入：

```
"NoahLiu/native-gui/i18n" @i18n,
```

## 词表格式

内置极简 TOML：顶层键为中文原文，段头之后的键归进段前缀。

```toml
"返回" = "Back"
"复制安装命令" = "Copy install command"
[nav]
"基础组件" = "Basics"
[form]
min_len = "At least {n} characters"
```

- 顶层键必须写在任何段头之前（写反了不报错，只会整表静默查不到）。
- `[meta] locale = "en"` 标记语言，放最后。
- 内置控件词表段：`gui.ui.dialog` / `gui.ui.message_box` / `gui.ui.datepicker` / `gui.ui.validation` / `gui.ui.edit`。

## 加载与切换

```moonbit
@i18n.i18n_load(EN_CATALOG)            // 切英文：加载英文目录
@i18n.i18n_reset()                     // 回中文（内置目录）
@i18n.i18n_load_fallback(EN_CATALOG)   // 只当回退目录（当前语言查不到才查它）
@i18n.i18n_extend(EN_CATALOG)          // 增量补条，不动已有键
@i18n.i18n_locale()                    // 当前语言码
```

中文态不加载本目录即回落中文（内置目录 `builtin_default()` 就是中文本体）。切换是运行时行为：`on_locale_change(f)` 注册回调拿句柄，`off_locale_change(h)` 退订；界面刷新由业务侧在回调里驱动（showcase 的做法：广播 + 路由 `localize_remount` 原地重挂页内容）。

## 查译

| 函数 | 用途 |
|---|---|
| `t(key)` | 查不到返回 `None` |
| `t_or(key, default)` | 查不到回落 default |
| `t_with(key, [("n", "3")])` | 带插值，占位写法 `{name}` |
| `t_with_or(key, vars, default)` | 带插值 + 回落 |
| `t_count(key, n)` | 复数：按语言选 one/other 形态，模板里用 `{n}` 取数量 |
| `interp(tmpl, vars)` | 纯插值，不查表 |

内置控件文案无需查表：加载词表后对话框、日期选择器、编辑菜单、校验提示自动跟随。

## 键怎么写

showcase 的键口径：键 = 中文原文（描述用 `desc§` + 中文标题），分组前缀 `nav.` / `seg.` / `form.` / `menu.`。这样中文态零词表也能跑，英文态一条目录全量覆盖。
