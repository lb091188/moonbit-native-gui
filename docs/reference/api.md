# API reference

The complete API reference is generated on mooncakes.io from the source doc comments: types and function signatures per package, documentation, and links to source lines, with a version switcher for past releases.

**[Open the native-gui API reference ↗](https://mooncakes.io/docs/NoahLiu/native-gui)**

Per-package shortcuts:

| Package | Contents |
|---|---|
| [base](https://mooncakes.io/docs/NoahLiu/native-gui/base) | Reactive kernel (`Store` / `Signal` / `ListStore`), focus stack, key constants |
| [shell](https://mooncakes.io/docs/NoahLiu/native-gui/shell) | Menus, hotkeys, tray, notifications, open-with, timers |
| [widget](https://mooncakes.io/docs/NoahLiu/native-gui/widget) | Widget host: layout tree, hit-testing & event routing, draw traversal |
| [ui](https://mooncakes.io/docs/NoahLiu/native-gui/ui) | Full widget constructor set (see [Components overview](../components/index.md)) |
| [render](https://mooncakes.io/docs/NoahLiu/native-gui/render) | Canvas, bitmaps, images & PNG (see [Canvas](../components/canvas.md)) |
| [text](https://mooncakes.io/docs/NoahLiu/native-gui/text) | Font families, fonts, rich text & span attributes |
| [theme](https://mooncakes.io/docs/NoahLiu/native-gui/theme) | Palette derivation & change subscription |
| [icons](https://mooncakes.io/docs/NoahLiu/native-gui/icons) | Vector icons |
| [sys](https://mooncakes.io/docs/NoahLiu/native-gui/sys) | System capabilities (see [Overview](../capability/sys.md)) |
| [input](https://mooncakes.io/docs/NoahLiu/native-gui/input) | Editing kernel & key codes |
| [win](https://mooncakes.io/docs/NoahLiu/native-gui/win) | Platform window layer: windows, shortcuts, icons, IME, message boxes |
| [dbus](https://mooncakes.io/docs/NoahLiu/native-gui/dbus) | Linux D-Bus calls: tray SNI, notifications, media, network etc. |
| [chart](https://mooncakes.io/docs/NoahLiu/native-gui/chart) | Charts & the cross-cutting interaction layer |
| [mdview](https://mooncakes.io/docs/NoahLiu/native-gui/mdview) | Markdown view |
| [style](https://mooncakes.io/docs/NoahLiu/native-gui/style) | Stylesheets (see [Layout & styling](../guide/layout.md)) |
| [i18n](https://mooncakes.io/docs/NoahLiu/native-gui/i18n) | UI copy localization |
| [router](https://mooncakes.io/docs/NoahLiu/native-gui/router) | Single-window page routing |

Optional standalone modules: [gui-media](https://mooncakes.io/docs/NoahLiu/gui-media) (audio & video), [gui-webview](https://mooncakes.io/docs/NoahLiu/gui-webview) (embedded WebView).

Usage and recipes live in the guide on the left; the API reference is authoritative for signatures.
