features:
  - title: One codebase, three platforms
    details: Native windows on Windows / Linux / macOS, with widgets looking the same everywhere; the system light/dark mode and accent color are followed by default, and the theme is customizable.
  - title: Declare the UI, let data refresh it
    details: Describe the interface as a tree in code and mount it with one mount_window call; when data changes, the bound interface refreshes itself — no manual refresh glue.
  - title: Desktop capabilities out of the box
    details: Tray, notifications, menus, global shortcuts, file dialogs, drag & drop, clipboard, autostart — ready to use.
  - title: A complete widget set
    details: Forms, tables, virtual scrolling, charts and a Markdown view are all included; the embedded browser and audio/video playback are optional add-ons that keep the default dependencies lean.
  - title: Lightweight
    details: Only what you use gets compiled — unimported packages never enter your binary; no heavyweight graphics engine, so artifacts stay small and start fast.
  - title: Unavailable means clearly reported
    details: When a capability is missing on this machine, you get an explicit reason — no silent failures, no crashes.
