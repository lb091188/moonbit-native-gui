# native-gui 测试用例

> 五个示例应用 × 三平台（Linux / macOS / Windows），按「**应用 → 页面 → 段落**」组织，顺序与真机操作顺序一致：一个应用跑一遍就能连着测完，不用来回跳。每条只写本条的检查点，其他条目的内容不串进来。
> 编号与 `测试文档/index.html` 记录台一一对应（`HL` / `SC` / `BR` / `AU` / `VD`），网页里点通过的条目就是这里的条目；记录台加载本文件现算清单与条数，**本文件是用例的唯一事实源**。
> 共 152 条：Hello 7、Showcase 97、Browser 23、Audio 14、Video 11。

## 怎么用

1. 通过本地 HTTP 服务打开 `测试文档/index.html`（VS Code Live Server、`python3 -m http.server` 均可；file:// 双击会被浏览器拦掉用例读取，页面会给横幅提示），顶栏填当前 commit。
2. 选平台 → 选应用，按本文件的顺序逐段往下点：通过 / 失败 / 跳过。失败项在备注里写一句现象（读数、报错行、位置偏移量）。
3. 一个应用测完再换下一个；同一平台测完再换平台。三个平台的结果互相独立，网页里按「平台 + 应用」分开记。
4. 要交给 AI 修时，用执行页的「失败 → AI 提示词」，得到的是按测试环节分组的失败清单。
5. 没有示例入口的功能（字距 / 虚线 / 最大化）走**附录 D**：直接跑对应的 `moon test`，读数按那里的判据对。

勾选约定：本文件里的 `- [ ]` 是「本轮人工勾选」，与网页记录**择一即可**（网页记录更完整，能带 commit 与历史）。附录 D 不进网页记录，`moon test` 就是判定。

## 0. 公共前置

| 项 | 内容 |
|---|---|
| 构建 | 仓库根执行 `cd gui && moon check --deny-warn` 应为零错误零警告 |
| 启动 | 进示例目录执行 `cd examples/<名字> && moon run .`（每个示例目录是独立模块）；产物路径见 `docs/zh/build.md` §5「新增示例模块」 |
| 平台 | Linux（Ubuntu 24.04 + X11 + XFCE）、Windows（Win32 10/11）、macOS（Apple Silicon）三平台同一份清单，均已真机执行；平台差异记进备注与附录 A |
| 媒体前置 | audio / video 需要 ffmpeg：装了 brew 时 pkg-config 直探，没装时 prebuild 自动下载 vendor 归档（stderr 会打印下载行与 sha256 校验通过） |
| 断言口径 | 「出图 / 有反应 / 读数对得上」都算通过；视觉类以肉眼可辨为准，平台差异记进备注 |
| 回报格式 | `编号 + 现象 + 截图（能截就截）+ 退出时读数行`，例：`SC-4.5 拖列边界不跟手；TABLE wins=1 cols=2` |

## 2. Showcase（`cd examples/showcase && moon run .`）

组件库演示板：侧栏 15 个页面，每页顶部还有一排**段**标签（segmented）。测法固定为：**点开一页 → 切到某段 → 段内逐项操作 → 下一段 → 下一页**。切换段只改可见性，各段滚动位置会各自保留。

> `SC-0.1` 是整板导航，先测它，后面每页都靠它跳转。

## 附录 A 平台差异（不是 bug）

三平台（Linux / Windows / macOS）已按同一份清单在真机上跑过，下面是仍然存在的**平台差异**——属于系统约束或已声明的边界，不是缺陷。

| 现象 | 说明 |
|---|---|
| 通知在裸 `moon run` 下报「后端不可用」（macOS） | `NSUserNotification` 只认从 `.app` bundle 起的进程，裸二进制投递被系统静默丢弃。复验走 `moon build examples/showcase --target native && scripts/make_app.sh showcase` |
| 菜单栏出现在屏幕顶部而非窗口内（macOS） | 系统约定：菜单条属 App 不属于窗口，多窗时后挂的赢 |
| 全局热键只认 US 布局的物理键（macOS） | 走 Carbon 硬件键位，非 US 键盘同一物理键字符不同 |
| 无边框形态下窗口上没有系统最大化按钮 | 系统标题栏的三键（最小化 / 最大化 / 关闭）由装饰提供，`set_borderless` 之后装饰被去掉。自绘标题栏要自己放这个键，用 `set_maximized` / `is_maximized`（见 SC-10.1）；默认形态下按系统按钮即可最大化 |
| 播放器控制族（MPRIS）给 Unsupported（macOS / Windows） | 无对等物，属声明过的边界 |
| 无合成器时窗口透明度静默无效 | `set_opacity` 依赖合成器，无合成器不报错也不生效 |
| 单实例在没有会话总线的 Linux 上落 AF_UNIX 套接字档 | D-Bus 知名名声称失败（headless、无 dbus 的桌面）时门面顺延到套接字档，语义与 dbus 档一致（进程唯一 + 唤起已有实例），只是通道不同；读数见 SC-11.11 |
| macOS 崩掉的首实例在 `$TMPDIR` 留一个套接字残桩 | 下次启动先试连，连不上就撤掉残桩重新 bind 接管，不需要手工清；文件名带 uid，多用户共用 `/tmp` 时互不认领 |
| Windows 上唤起对方要对方在抽消息 | WM_COPYDATA 由同步投递送进首实例的消息队列，首实例卡在长任务里时第二实例最多等 3 秒后报「对方没在抽消息」，不会吊死 |

## 附录 C 界面基准（`native-gui-design` 技能，2026-10-21 统一后）

视觉问题按这六条判，不按个人手感判。基准细节见 `.agents/skills/native-gui-design/references/`。

| 判据 | 合格线 |
|---|---|
| 间距 | 只用 `2 / 4 / 6 / 8 / 12 / 16 / 24`；表单行距 8、卡片内 12、页面外框 16、区块间 16 或 24 |
| 字号 | 文字走角色（Title 18 / Section 14 / Body 13 / Secondary 12）；只有数字型强调与排版演示才写 `font_size=` |
| 圆角 | 控件 4、卡片与面板 6、对话框与浮层 8；不出现大于 8 的圆角 |
| 层次 | 靠底色（`bg_page` → `bg_panel`）与 1px `border` 分层；**没有投影**，也没有窗口背后毛玻璃 |
| 颜色 | 一律 token；界面代码里出现十六进制即隐患（唯一例外：饱和主色底上的反白 `#ffffff`，token 集没有反白档） |
| 状态 | 可点的有 hover / active，输入类有 focus；用状态桶，不自己叠一层假悬停 |

自查脚本口径（改完界面可跑）：`padding/row_gap/column_gap` 不在刻度内 = 0 处；`border_radius > 8` = 0 处；`color="#..."` 只允许那两处反白。

## 附录 D 库级测试（数量型判据）

字距与虚线现在有示例入口（SC-13.3 / SC-13.5），目视判过之后仍建议跑一遍库测试核读数；**最大化**在示例里只有窗口级入口、量不到客户区尺寸，判定以库测试为准。读数口径记在这里，路线图只留功能点。

| 项 | 命令 | 用例与判据 |
|---|---|---|
| 字距 | `cd gui && moon test text` | `spacing_wbtest` 三条：①「量宽差 = 字符数 × spacing」——`a` / `abc` / `中文测` / `hello world` 在 S=1/2/4 下量宽差都是字符数 × S（容差 1px），三平台读数应当一致；②「绘制与测量同源」——同串同原点，S=8 的墨迹右界严格大于 S=0（绘制那趟也吃到了字距，不只是测量被骗过去）；③「同串不同字距不串味」——缓存键带上 spacing |
| 虚线 | `cd gui && moon test render` | `dash_wbtest` 五条：①100px 直线配 `[10,10]` ⇒ 5 段、段长 10、首段起点 5、周期 20；②offset=10 ⇒ 首段起点 15；③`set_dashes([])` 回整条实线；④闭合矩形按图案断段（首尾留缝，不绕回补相位）；⑤虚线进 save/restore。**唯一的跨后端校验点**：Linux cairo 档的段数与首段长度必须与 macOS / Windows 光栅器读数一致 |

| 行数钳制 | `cd gui && moon test text` | `text_wbtest`「max_lines 行数钳制」一条：长文钳到 2 行后测量高不超过 2 行行高、明显矮于整段（说明截断生效）；不超限的短句加 `max_lines` 后高度与不限时一致（说明不误伤）；`max_lines=1` 等价单行截断，高一行、宽不超可用宽。真机可见形态随 SC-1.4 复验（文本件口径批已合入） |
